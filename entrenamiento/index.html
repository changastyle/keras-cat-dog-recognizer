4 · ReLU y MaxPool: limpiar y encoger

ReLU corta los negativos a 0 (quedarse solo con activaciones). MaxPool 2×2 reduce el mapa quedándose con el máximo de cada ventana.

Mapa 4×4 (tras ReLU)
→
Salida 2×2
ReLU(x) = max(0, x)   ·   MaxPool([0.8, 0.3 ; 0.1, 0.6]) = 0.8

En tu red: 100→98 (conv valid) → 49 → 47 → 23 → 21 → 10. Cada MaxPool divide por 2 el tamaño, mientras los canales crecen 32→64→128: menos píxeles, más significado.

GlobalAveragePool(None, 128)0promedia cada mapa → vector
Dense sigmoide(None, 1)129vector → P(perro)
GlobalAveragePooling promedia cada mapa 10×10 a un solo número → vector de 128. El Dense final lo mezcla con 128 pesos y lo comprime con la sigmoide: σ(x) = 1/(1+e-x), siempre entre 0 y 1.

6 · Entrenar = equivocarse y corregir

El bucle mágico. En cada lote de 32 fotos ocurre esto:

1. FORWARD  : fotos → matrices → P(perro) ← la red "opina"
2. LOSS     : error = binary_crossentropy(predicción, etiqueta)
3. BACKWARD : gradientes → qué pesos causaron el error
4. UPDATE   : adam empuja cada peso un poquito en contra del error
loss train loss validación pulsa ▶

Tres trucos que ya están en train.py

TécnicaQué hacePara qué
RandomFlip + RandomRotationvoltea y gira cada foto al azarel modelo ve "fotos nuevas" gratis → generaliza (aumento de datos)
Dropout(0.3)apaga 30% de neuronas al azar en cada pasoninguna neurona memoriza sola → evita overfitting
EarlyStoppingpara si la validación deja de mejorar (4 épocas de paciencia)no entrenar de más = no memorizar

7 · De .keras a .onnx: limpiar y exportar

El modelo entrenado tiene capas que solo sirven en training. El notebook las quita antes de exportar.

modelo = keras.models.load_model("modeloCNN3.keras", compile=False)
x = keras.Input(shape=(100, 100, 1))
for capa in modelo.layers:
  if RandomFlip o RandomRotation: saltar ← aumento ≠ inferencia
  if Dropout: capa(x, training=False) ← todas las neuronas activas
  else: x = capa(x)
modelo_inferencia = keras.Model(entrada, x) # "perros_gatos_inferencia"
modelo_inferencia.export("perros-gatos-cnn-ad3.onnx", format="onnx")

Se verifica que el modelo limpio predice idéntico al original y se exporta. ONNX es un formato estándar: el mismo archivo corre en Python, en un servidor… o en tu navegador con ONNX Runtime Web (WebAssembly).
